# JUICY Academy — by Nazerke

Закрытая кулинарная академия для подтверждённых клиенток JUICY. Функциональная база — [текущее демо](https://nazerke-academy-demo.vercel.app/).

**Исполнитель разработки:** Codex (CODEX_PRIMARY). **Исходное ТЗ:** [Issue #1](https://github.com/kires0214/Nazerke-academy/issues/1).

Работа в одном репозитории; интерфейсы: публичный сайт, закрытая академия и JUICY Studio. Развёртывание: **DEV → PROD** на Vercel; Neon PostgreSQL, Cloudflare Stream, Telegram API — специализированные подключённые сервисы.

> **Внимание:** на момент инициализации репозиторий публичный. Никакие секреты, клиентские данные и неопубликованные частные материалы не коммитить. Перед размещением фотографий владельца, видео и любых защищённых материалов убедиться, что репозиторий закрыт для посторонних. Подробности в `docs/SECURITY.md`.

Документация и архив исходного демо добавляются в следующем коммите. Этот README не означает, что production-бэкенд уже существует.
